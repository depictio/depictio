Three ways to take a component with you

Live frame

Point an <iframe> at the export URL. Depictio renders on request, so the embed tracks the dashboard.

needs Depictio reachable

Saved file

Download the same URL once and keep the HTML. It carries its own data and renderer, so it works with Depictio switched off.

frozen at download time

Plotly spec

Ask for format=json and get {data, layout, config}. Render it with your own plotly.js and restyle it freely.

only where a figure is built server-side
