Depictio
component export

Three worked examples of the same API, each in a different host context. Every figure on every page is fetched live from a Depictio instance running on another origin and drawn by the host page's own plotly.js. No iframes, no Depictio JavaScript, no build step.

Each figure carries a collapsible panel showing the exact request that produced it, and each page's controls are built from the export manifest, so nothing here has to be taken on trust.
