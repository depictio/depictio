What the manifest promises, before any figure is fetched

A host does not have to discover limitations by hitting them. The manifest declares formats per component, so a page can plan its layout — and decide what to do about the gaps — from one request.

    What a fallback costs

    Each HTML fallback is a self-contained page carrying the whole React bundle: ~7 MB apiece, against a few hundred KB for a spec. The fallback exists so nothing is missing, not because it is the cheap option.

    This is the argument for JSON in one number, and it is why the text and interactive panels below are the only ones that should be framed.

    Two kinds of limitation

    Inherent. A text block is prose and an interactive component is a widget. Neither is a figure, so neither will ever have a Plotly spec. format=html is the correct answer permanently, not a stopgap — and for an interactive component it is a genuinely good one, because the framed widget can post its selection back to the host page and drive the figures around it.

    Cost. The fallback works, but it is heavy. A page that frames several components pays megabytes for what a spec delivers in kilobytes, which is the whole reason to check the manifest first and design around what exports cleanly.
