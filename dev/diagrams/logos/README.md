# Logos used by the diagrams

Embedded by `Sketch.image()` (base64, so the SVG/PNG outputs are self-contained).
Each mark belongs to its project and is used only to name that project in our docs.

| File | Source |
|---|---|
| `nf-core.png`, `multiqc_icon_color.svg` | `depictio/viewer/public/logos/` (nf-core, MIT) |
| `nf-core-<pipeline>.webp` | depictio-docs landing page (`logos/templates/*_light.webp`), from each nf-core pipeline's logo |
| `nextflow.png` | Nextflow brand assets (Seqera) |
| `apptainer.png` | apptainer.org docs (`_static/logo.png`) |
| `depictio.png` | `docs/images/logo_icon.png`, downscaled |
| `docker.svg`, `github.svg`, `githubactions.svg`, `mongodb.svg`, `redis.svg`, `anaconda.svg` | simple-icons 13.0.0 (CC0), brand colour added |
